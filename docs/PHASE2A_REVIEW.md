# Phase 2a v0.1 設計の技術点検

2026-10-28 日本時間。対象: [設計案](PHASE2A_DESIGN.md)、[ADR-0002](adr/0002-phase2a-contact-research.md)。設計責任者による自己点検であり、別担当の独立承認とは呼ばない。workerの実装レビューは承認・実装後に責任者が別に実施する。

## 技術判断

**提示した範囲で実装可能な研究計画。** 本点検後、ユーザー本人の「うん」によりv0.1の研究仕様とworker実装開始が承認された。記録は設計書§9・D036・PR #7を参照。良い予測値が出ること、認知能力が識別できることを前提にしない。

## 点検した問題と扱い

| 論点 | 設計での扱い |
|---|---|
| 「接触」と「三振しない」の混同 | y_contactと4タグを分け、公開三振回避能力の正解にしない |
| 見送った球の接触は未観測 | 対象を観測された通常スイングに限定。全投球へ振らせた介入の能力推定にしない |
| 既存のスイングラベルへの上書き | y_contactを別に作り、旧y_swingとの一致を検査する。旧ラベル・結果を保存 |
| 打者効果追加で未知打者まで悪化する可能性 | C1の基底係数を固定しC2を残差だけに限定。未知・小標本のb=0でC1と同じ予測 |
| 2025の既閲覧 | 新しい未使用holdoutと称さず、2024までで選択・凍結して既閲覧年度の再現比較にする |
| カテゴリ・標準化・対象者の情報漏洩 | 2023だけで決定。fitで2025を開くと例外になる検査を要求 |
| 候補失敗を無視した選択 | 一つでも未収束ならfit未完了。全候補を報告し、成功例だけで選択しない |
| 近い損失の非推移的な同等判定 | 個別の相互比較ではなく、全候補最小値+1e-10の集合から選ぶ |
| 小集団・単一クラス・タグ別評価 | 分母とnull理由を保存。結果タグ別を校正や技能の比較と呼ばない |
| 旧成果物・改行・入力来歴 | 新規領域へ分離、入力生バイトhash、新出力UTF-8/LF、ソースLF正規化の規約を明記 |

## 数式・小例の確認

C2の残差目的はlambda>0で厳密に凸。勾配はsum(p−y)+lambda*bで、根は[-n/lambda,+n/lambda]内にある。指定のBrent区間が根を挟むことと、未知・小標本のb=0の同値性を確認した。

実投球データを読まず、人工の60球・3ラベル配列（全接触／全空振り／混合）×lambda 10/50/200の9例を数値点検。全例で根の区間・正の二階微分・有限な解を確認し、最大の1球あたり残差勾配は7.64e-15だった。これは設計式の点検であり、Phase 2aの研究コード・実データ学習・予測結果の実施ではない。

既存FeatureEncoderとdescription allowlistを読み、特徴と対象ラベルが分離できることを確認。MLBの規則用語と照合し、タグをまとめた三振回避モデルにしない方針を保持した。
