# ホームの対戦カードと順位表

2026-11-26の本人指示と[参照したメイン画面](https://pennantspirits.ifdef.jp/manual_g_1.html)に基づく。ホームの対戦カードと順位表の配置・密度・項目順を見直す。

- ホームでは共通の「順位表」「差」バーの下に自リーグの6球団、その直下にもう一方の6球団を並べる。リーグの境目に区切りを置く。これはD065のホームにおける左右表示に代わる。成績・年度別の専用画面は従来の表示を使う。
- 1行の順は順位、短縮球団名、勝敗分、勝率、首位との差。勝敗は「0勝0敗0分」、勝率は「.000」「.500」「1.000」、差は小数1桁で表示する。各リーグの先頭行では差の欄を空ける。開幕前は既存の球団順を表示上の1〜6番として出し、成績は0、先頭以外の差は0.0。当該リーグで試合が始まった後は既存の順位と同率の扱いを使用し、比較に必要な記録がない差は「—」とする。操作球団の行を強調し、順位表のためにエンジンや集計、保存内容を変更しない。
- 広い画面では、対戦カードを主欄、順位表をその右の欄に置く。縦持ち・狭い画面では、対戦カードの直下に、全幅で同じ順位表を置く。上下固定バーと進行の操作は継続し、カードと順位表の余白を詰める。得点または状態が見える枠と、自球団カードの強調・タップ範囲を保つ。休養日と試合前後でカード寸法を変えない。
- 配色、文字、球団名の表現はAndroid版のものを使う。読みやすい密度を保ち、320dpと文字拡大でも順位表の各項目に横スクロールなしで到達できるようにする。参考作品のロゴや素材は使用しない。月間日程や他画面の構成、球団戦力など新しい機能は今回の範囲外。

## 確認

新規開始時と当日結果の表示後、両リーグを選択した場合を検証する。リーグの順序、列の配置、勝敗分と成績表記、0試合・同率・首位との差、休養日の枠寸法を確認する。縦持ち、広い画面、320dp・文字拡大をエミュレータで撮影する。既存試合とセーブを回帰確認し、検証済みAPKをGitHub Releasesへ添付する。
