# Phase 3b案v0.1の設計点検

2026-10-29 日本時間。[設計案](PHASE3B_DESIGN.md)と[ADR](adr/0005-phase3b-numeric-generator.md)の承認前の点検記録。責任者と読取り専用サブエージェントによる点検であり、外部査読・ユーザーの仕様承認・実装レビュー合格を意味しない。

## 点検したこと

- 25×36の細セルが72粗セルを隙間・重複なく分割し、細セル数m_Cの合計が900となる。
- 基底Bは有限EVで0.96、尾部で0.04、全体で1に積分される。全細セルの基底確率は1/900。
- H0/H1は正・合計1で、同じ粗セル確率q_Cへ戻る。粗セル内の件数が一様なら同値、非一様なら異なり得る。
- 共通のセル内密度が対数比から消えるため、主差は900カテゴリの差と一致する。この事実は、セル内一様性や指数尾部を主比較で検証できないという限界でもある。
- 責任者が新しいraw値を読まず、公開済み集計・人工表・別式・数値積分で8項目を確認。積分1、粗確率の最大差1.95e-16未満、密度比とカテゴリ比の最大差2.67e-15未満。真の分布をH0/H1とする人工例ではそれぞれが勝つため、H1優位を完了条件にしない。

## 批判と反映

1. 旧J1の希少区分確率を数値生成へそのまま継承する根拠はない。新H0/H1共通の合計擬似度数1を別の研究設定とし、旧研究を変更しない。尾部の確率変更をH1の学習成果と数えない。
2. 合計1件の平滑化は弱い。空セルには正確率があっても非常に小さくなり、後続年度で損失が大きくなる可能性がある。結果を見てαや区分を変更しない。
3. EV≥120の2023対象は1件であり、H1の尾部LAにも過集中の恐れがある。EV<120/≥120の件数・損失・主差への寄与を分ける。尾部尺度5も共通仮定で、主差からは検証できない。
4. 5mph/5度は研究解像度。丸め幅・測定誤差・小数桁の正確さとは呼ばず、数値抽選と真の連続分布の妥当性を区別する。
5. q_Cは共通だがαはH1のセル内分布にも影響する。平滑化の影響を完全に除いた実験、細かい相関だけの効果とは呼ばない。
6. 各年N/粗72件数の既存3a集計との一致を受入れ条件に追加。参照年度の読取りもfitと凍結後evaluateに分ける。

KDE、経験分布の補間、旧J0/J1の同じセル内拡張も検討した。今回の目的には追加仮定・計算量が増えるか、既存の差の再表現になるため主案としない。代替を一般に不適切とは結論しない。

数理・年度順序・情報境界・乱数・旧研究保存に重大な矛盾は見当たらない。ただし、本人の範囲承認は未取得。実データfit・worker実装・新しい生成器の採用はいずれも未実施。承認後の実装を責任者が独立レビューする工程は別に必要。
