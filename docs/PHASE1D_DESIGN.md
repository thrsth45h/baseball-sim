## 0. 初めに決める範囲

**Phase 1dは、合成データにおける識別検証と、将来のStatcast比較を可能にする評価契約までとする。**
主な問いは「同じ程度に振る条件でも、手掛かりの精度を上げると固定課題の識別が改善するか」「その結論は推論の仮定が外れた場合にも維持されるか」である。

| Phase 1dに含める研究用実装 | 今回含めないもの |
|---|---|
| 世界の生成条件と打者の推論仮定の分離 | MLBデータへの新規学習・ハイパーパラメータ選択 |
| 選球眼・積極性・分散項の効果を区別する実験 | 実選手の認知能力や公開能力1〜20の推定・確定 |
| 単一の主要比較、事前固定した感度分析 | M2 dや既存eye_shiftからの能力換算 |
| 潜在知覚を周辺化する確率の合成参照実装 | 接触・打球・見逃し判定・配球AI・打席遷移 |
| 入力情報表と明示入力されたローカルファイルの監査 | 新規ネットワーク取得、ゲーム・Androidへの組み込み |
| 既存契約の回帰検査、来歴・乱数・結果出力 | 既存M0/M1/M2・Phase 1b/1cのコードや結果の改変 |

独立した早期観測が得られない場合も、Phase 1d全体を未完にしない。入力監査の結論を「知覚データなし」として完了できる。**MLB接続可能性の監査完了と、認知的な識別成功は別である。**

本設計の承認対象はこの研究範囲・実験条件・検証契約。研究で肯定的な結果が得られても、本番採用や能力係数の承認を自動的に行わない。

## 1. 現状・問題・推奨理由

Phase 1bは最終位置等を条件にした実際のスイングの予測研究。Phase 1cは人工の早期手掛かり・知覚・閾値から行動を生成する研究である。研究PR #2は合成専用として独立レビュー・マージ済みで、認知妥当性や製品係数は未承認。

Phase 1cの単一路 r→σ(r) とGaussian事後の導出は、その仮定内では整合している。しかし、(1)分散項も全体の振りやすさを変える、(2)生成器と推論器が同じ仮定を共有する、(3)単一の知覚抽選の確率では既存モデルと比較できない、(4)観測された行動だけで心理機構は一意に決まらない、という問題が残る。

そのため、自由な認知パラメータを増やして実データへ直ちに学習する案より、固定課題・反例・誤特定を先に調べる案を推奨する。これは開発を停止する提案ではなく、次の実装を反証可能な小さな研究に限定する提案である。

## 2. 分離する状態・インターフェース

名称は実装契約上の役割を示す。Pythonクラスの詳細は実装担当が決めてよいが、情報境界は変更しない。

| 状態・処理 | 入力・保有情報 | 禁止する参照・作用 |
|---|---|---|
| WorldSpec | Qの真の分布、初期運動、後半変位 | 打者の推論用事前分布を自動変更しない |
| SensorSpec | バイアス・誤差相関・誤差形、原始量σ(r) | 能力による期限延長・追加の判断ボーナス |
| Observation | 期限までの軌道標本のコピー | 結果、実到達位置、期限後座標への参照 |
| Measurement | 初期軌道を投影した感覚測定M、固定期限 | 真の球種・球速・狙い・結果の付帯情報 |
| InferenceSpec | 打者が仮定する事前分布・後半分散 | WorldSpec/SensorSpecの真のバイアス等へのアクセス |
| infer(M, σ, InferenceSpec) | 予測位置の平均・分散・期限を返す | rを別に受けて再度精度を補正すること |
| Policy | Belief、投球前カウント、a、行動乱数 | 真値・世界条件・rの直接参照 |
| Evaluator | 判断後の真値結合、指標・条件付き予測積分 | 評価ラベルによる実行済み判断の書き換え |

σ(r)は一つの関数で生成し、感覚ノイズの尺度と、推論器が仮定する測定尤度の尺度へ同じ値を使う。後者から導く事後分散の変化は別の能力ボーナスではない。SensorSpecの誤特定条件はrから独立に作用し、推論器はその真の値を受け取らない。

推論事前と世界の真の分布を、同じ可変設定オブジェクトで共有しない。世界だけを変える介入で推論設定のハッシュが変わらず、推論設定だけを変える介入で投球列のハッシュが変わらないことを検査する。

## 3. 固定するモデルと課題

### 3.1 基準値

Phase 1cの係数を**比較用の未較正値として凍結して再利用**する。値が適切と確認されたためではない。

| 項目 | 研究用の基準値 |
|---|---|
| 判断期限 / 投影時刻 | 0.18秒 / 0.42秒 |
| 真のQの平均 / 軸SD | (0,0) / (1.1,1.1)、独立 |
| 真の後半変位L | 軸SD=0.3、平均0、独立正規 |
| 推論用事前 | Q~N(0,1.1² I) |
| 推論用後半分散 | 0.3² I |
| 感覚尺度 | σ(r)=0.12+0.45 exp[−0.08(r−13.5)] |
| 標的t / スコア | t=(0.35,−0.15)、g(X)=1−||X−t||² |
| カウント基準 / 温度 | τ=0.08 balls−0.12 strikes、T=0.65 |
| 研究用r / a | r∈{1,8,13,17,20}、a∈{−0.7,0,+0.7}、許容域a∈[−1,1] |

全て人工座標・合成時間上の研究設定。1〜20の効果幅や13.5の認知的意味を測定したとは扱わない。係数を学習せず、結果を見て有利になるよう変更しない。

早期運動からQを先に生成し、X=Q+Lを後で作る。初期運動の軸速度は独立N(0,1)、標本時刻は0.06/0.12/0.18秒とし、位置はQ+速度×(時刻−0.42)とする。観測は期限まで、M=O+感覚誤差、Gaussian推論の事後は μ=wM、v=wσ²+0.3²、w=1.1²/(1.1²+σ²)。バイアス等の感度条件でも推論器はこの固定仮定を使う。

### 3.2 固定課題とスコア2種類

評価用ラベルは F=1{g(X)≥0} とする。これは人工標的の半径1以内かどうかで、幾何ゾーンや実際の正解行動と同一視しない。FはEvaluatorだけが参照する。

| スコア | 定義 | 目的 |
|---|---|---|
| P0: 現行の期待スコア | s0=1−||μ−t||²−2v | Phase 1cの基準 |
| P1: 平均位置のみ | s1=1−||μ−t||² | 分散項の全体率への効果を調べる診断専用 |

両方とも π=logistic((s−τ+a)/T)、行動は共通一様乱数u<πで抽選する。

**固定rではvが全投球で一定なので、s1=s0+2v。** よってP0/P1の順位・ROC/AUCは同じで、π0(a)=π1(a−2v)である（両方のaが許容域内の場合）。この同値性を検証する。P1を「識別性能が向上する新モデル」と報告してはならない。

この事実から、まずP0を基準としてrの効果を調べる。分散項の削除を本番の修正案として採用しない。P1はE[g]という意味を失うことも明記する。

### 3.3 指標

- 識別AUC: F=1の球のスコアがF=0より高い確率。tieは0.5。主要比較ではカウント0-0に固定する。
- 期待Swing率: Σπ/n。実現Swing率も保存するが、性能比較の主要指標にしない。
- 期待有利球反応率TPR: ΣFπ/n_F。期待不利球反応率FPR: Σ(1−F)π/n_nonF。
- 位置MSE/軸、固定gの推定MSE。補助指標であり、行動識別の代替にはしない。
- 人工方針の損失: 平均[max(g(X),0)−πg(X)]。仮に「振る=g、見送る=0」とした課題内の損失で、得点損失ではない。
- 人工幾何ゾーンabs(Xx)≤1かつabs(Xz)≤1による率は参考値。公表Chase%とは呼ばない。

全て分母を保存する。空のF群等があれば値はnull・理由付きとし、0や完全性能へ置換しない。

## 4. 研究課題・事前の比較計画

### 4.1 D1: 能力と積極性の作用検査

同じ投球・感覚用基礎乱数・行動乱数でrとaを独立に変更する。aだけを変えてもMeasurement/Belief/scoreは不変。r→σを固定するとr差の効果は消える。知覚を固定してr関連の設定を変えてもPolicyは不変。rを変えて期限・標的・τ・Tを変えない。

真の到達位置、球種、球速、狙い、結果、期限後座標を変更しても、同じ観測・測定・乱数なら判断は変わらない。期限直後の座標アクセスを例外で検出する検査も引き継ぐ。r=20でも同じ初期手掛かりを持つ異なる後半を識別できない。

### 4.2 D2: 主要比較は一つ

**基準世界、P0、0-0における ΔAUC=AUC(r20)−AUC(r8)** を唯一の主要比較とする。他のr・カウント・感度条件は副次・探索的と表示する。

研究上の方向仮説はΔAUC>0。95%区間が0を上回れば `supported_under_assumptions`、0を含めば `inconclusive`、0を下回れば `not_supported`。これは固定した人工課題に対する結論であり、実用改善幅・MLB妥当性・製品採用の合格判定ではない。肯定的な結論をソフトウェアの完成条件にしない。

副次比較では同程度に振る条件を作る。各seed・world・r・カウントごとに、調整用の投球集合で期待Swing率が20%、40%、60%になる診断用閾値オフセットδを求める。a=0に固定し、式はlogistic((s−τ+δ)/T)。ラベルF・結果・評価集合はδの調整に使わない。seedごとに凍結適用した結果を等重み平均し、良かったseedだけを選ばない。

δは観測された積極性の推定値ではなく、率を標準化する研究操作である。δとaを同時に自由推定しない。δは許容aの範囲外にもなり得るため、本番Policyのa上限を拡張する実装にしない。実装境界でも `diagnostic_rate_matching` と通常のa介入を別のモードにする。

二分探索はδ∈[−1,1]から始め、必要に応じて左右の絶対値を倍増し上限128、最大80反復、調整集合での率の絶対誤差≤1e-6で終了する。未収束は理由付き失敗とし、係数変更や評価集合での再調整をしない。

調整後のδを凍結して評価集合へ適用し、実際の期待Swing率・TPR・FPR・人工方針損失を比較する。評価集合の率が目標から3パーセントポイントを超えてずれたセルは `rate_match_not_transferred` とし、同率条件での結論を保留する。AUC等の他の有効な評価は保持する。3ポイントはこの合成実験の比較管理用で、製品の許容誤差ではない。

P1の同率用δはδ1=δ0−2vから導ける。同じ集合上の予測一致を検査し、独立に調整した偶然の差を改善と解釈しない。

### 4.3 D3: 生成器と推論器の仮定を食い違わせる

基準世界に対し次の単独変更6条件、計7条件を固定する。表以外を同時変更する交互作用実験は今回含めない。

| world_id | 真の生成・感覚条件だけの変更 | 推論器が使う仮定 |
|---|---|---|
| W0 | 基準 | 基準と一致 |
| W1 | Qの真の平均を(0.5,−0.5)へ | 平均(0,0)のまま |
| W2 | Qの真の軸SDを1.65へ | SD=1.1のまま |
| W3 | Mに感覚バイアス(0.35,−0.35)を加える | バイアス0のまま |
| W4 | 感覚誤差の軸相関ρ=0.5 | 軸独立のまま |
| W5 | 感覚誤差を分散1へ標準化したt分布、自由度5へ | 正規尤度のまま |
| W6 | 真の後半変位Lの軸SDを0.6へ | SD=0.3のまま |

W4はεx=zx、εz=0.5zx+sqrt(0.75)zz。W5は各軸独立でt5×sqrt(3/5)。σ(r)は全条件で同じ尺度関数。係数は意図的な人工ストレス条件で、MLBでの誤差分布の推定値ではない。

W0〜W6で同じ推論設定を使う。ただし同率化のδは各worldの調整集合で別に求め、各worldの評価集合へ凍結適用する。これを別世界へ無調整で移した頑健性とは呼ばない。通常a介入のδ=0の成績も残し、同率化で隠れる分布変化を確認できるようにする。

全条件を必ず表示し、不利な条件を削除しない。頑健性の結論は「試した条件内」のみ。今回省いた異分散・球種混同・履歴依存・QとLの依存等も未検証として列挙する。

### 4.4 D4: 識別不能な反例を参照ケースにする

次の代替probitモデルを、現行logisticモデルとは別の数学的反例として保存する。

```text
A = 1{x+a−τ+σε+Tη>0}, ε,ηは独立標準正規
P(A=1|x) = Φ((x+a−τ)/sqrt(σ²+T²))
```

σ,Tが(0.6,0.8)、(0.8,0.6)、(sqrt(0.75),0.5)なら、全てσ²+T²=1。x∈{−2,−1,0,1,2}、a=τ=0で同じ行動確率になることを1e-12許容差で確認する。これを現行logisticモデルの非識別性の厳密証明と誤表示しない。

同様に、一般のlogistic入力ではs,τ,a,Tを同じ正の定数で拡大しても確率が不変であることを記録する。尺度を固定すればモデル内パラメータを推定できる場合があるが、その固定が認知機構として正しいという外的根拠にはならない。

自由なr/a/T/gを同時推定する復元実験は今回含めない。D4の完成は「推定に成功した」ではなく、「識別できない説明と、識別に必要な追加条件を明示した」で判断する。

## 5. 標本・乱数・区間・資源

| 項目 | 事前固定する値・方法 |
|---|---|
| root seed | 202610281、202610282、202610283の3本 |
| 各seed・worldの調整集合 | 独立4,096球 |
| 各seed・worldの評価集合 | 独立8,192球 |
| 条件の共有 | 同じseed/stage/pitch_idの世界・r・Policy間で基礎乱数を共有 |
| カウント | 主要比較は0-0。副次は同じ投球を12カウントへ置いた反実仮想比較 |
| 区間 | 主要ΔAUCとW0・40%同率比較のTPR差を、対応付き500回percentile bootstrapで95%区間 |

主要ΔAUCはseedごとのAUC差を等重み平均する。bootstrapはseed内でpitch_idを復元抽出し、同じ抽出をr8/r20に適用する。同率比較のTPR差は0-0、P0、r20−r8に限定し副次とする。調整集合と評価集合を独立に再標本化し、各回δを再調整して、その調整誤差も含める。複数指標の区間を独立した採用検定として扱わない。感度条件の区間追加は別計画とし、今回は点推定・seed別値を全件報告する。

bootstrapの500個の反復番号は固定する。調整未収束・空のF群等で無効な反復が一つでもあれば、その指標の区間はnull、`invalid_bootstrap` と無効理由・件数を保存する。成功した反復だけの選択や再抽選をしない。

カウントやrを変えた同じ球は独立標本として水増ししない。worldごとの一意投球数と介入レコード数を区別する。区間は仮定した合成母集団の変動を表し、人間の選手・試合・MLBへの一般化の区間ではない。

乱数方式を `phase1d-keyed-v1` として版管理する。UTF-8の `version:root_seed:stage:pitch_id:innovation` をSHA-256でハッシュし、big-endian整数をPython random.Randomのseedとする。stageはcalibration/evaluation/bootstrap。world/r/a/Policy名をキーへ入れない。投球生成のinnovation名は `q_x,q_z,motion_x,motion_z,late_x,late_z,sensory_x,sensory_z,action` に固定し、各キーから一つの基礎乱数を得る。

bootstrapではpitch_idの欄に反復番号0〜499を使い、innovationを `calibration_resample` / `evaluation_resample` とする。seedごと・反復ごとに別のRandomを一度作り、randrange(n)をその集合の球数回呼んで抽出indexを作る。同じindex列を全ての比較対象に適用する。1回の抽出ごとにRandomを同じキーで作り直して同じ球だけを抽出する実装にしない。

同じ一様基礎乱数を正規とtの逆CDFへ使う。CDF端の問題を避けるため、一様値は `(52bit整数+0.5)/2^52` とし0/1を含めない。binary64で丸めて1となることを避けるため52bitを使い、整数0と2^52−1の両端も検査する。W4の相関変換を含め、条件別に乱数の消費数を変えて他の投球をずらさない。Phase 1cの既存乱数版は変更しない。

出力の再現性は同じ実装・設定・依存版・seedを前提にし、同一環境では数値ペイロードのハッシュ一致を要求する。実行日時等の来歴と数値ペイロードは分ける。異なる環境の固定された単球参照推論は1e-12の数値許容差と版情報で確認する。積分の許容差は§6、集計の丸め差は明示した集計順序で扱い、全てを1e-12で同一視しない。

研究の完全実行は推論設定1個×7世界×3seed×5水準r。a/カウント/P0/P1間で同じBeliefを再利用し、全条件の投球行を巨大JSONとして保持しない。開発用smokeは各集合256球・seed先頭1本とし、結果には `smoke_not_study` と表示、主要結論を出さない。

大規模実行前にsmokeの時間・最大RSSを測る。予定する完全実行が30分またはRSS 1GiBを超える見積もりなら、最適化・分割方針を先に示す。完全実行で上限を超えた場合も、科学的条件を黙って縮小せず `resource_limit` として途中成果と未完了条件を報告する。これらは今回の研究の資源管理値で、Android性能要件ではない。

## 6. D5: 比較用の周辺確率の参照契約

### 6.1 対象

W0のGaussian関係だけを対象に、最終位置Xへ条件付けた予測確率を合成データで検証する。**Evaluatorの事後条件付けであり、ゲームの判断器にXを渡すAPIではない。**

各軸についてp²=1.1²、l²=0.3²とし、

```text
Q|X ~ N(αX, b), α=p²/(p²+l²), b=p²*l²/(p²+l²)
M|X,r ~ N(αX, (b+σ(r)²)I)
P(A=1|X,c,r,a) = E_{M|X,r}[logistic((s0(M,r)−τ(c)+a)/T)]
```

ここでs0はMに対する打者の事後から作る。XをそのままQと置いて感覚ノイズを足す方式とは違う。logistic(E[s0])で置換せず、行動抽選0/1の平均を検証用の正確な確率とも呼ばない。

### 6.2 数値検証

X∈{(0,0),(0.35,−0.15),(1,1),(2,−1)}、r∈{8,20}、a∈{−0.7,0,+0.7}、0-0の24ケースを固定する。

- 主実装は2次元Gauss–Hermite積分、次数32→64→128。exp(−u²)に対する節点u_i・重みw_iを使い、期待値は `Σ_i,j w_i*w_j*h(αX+sqrt(2*(b+σ²))*(u_i,u_j))/π`。正規化した全重みの和が1となることを検査する。
- 独立した参照計算は標準正規座標上の入れ子の適応積分。各軸[−10,10]、絶対・相対誤差要求1e-9。省いた正規裾の確率は別記する。警告・未収束を成功扱いしない。
- 全ケースで64対128の差≤1e-6、128対参照の差≤2e-6、確率が有限で[0,1]に入ること。
- 未収束なら `numerical_not_converged`。許容差緩和や別seedへの変更を黙って行わない。
- W1〜W6の条件付き密度や実CSV全件への推論は今回対象外。W0式の流用を拒否する。

固定ケースの積分精度検査は、実データにおける予測性能の検査ではない。後続でモンテカルロ近似を使う場合は、近似誤差と学習・標本変動を別に管理する計画が必要。
