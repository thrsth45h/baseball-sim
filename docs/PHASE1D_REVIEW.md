## 数式・数値の点検

- P0/P1は固定rで定数差。同じ閾値オフセットを調整すれば確率と順位が一致することを確認。分散項の削除を識別改善と報告しない契約を維持。
- σ,Tの二乗和が同じprobit反例と、logisticの尺度不変性を確認。現行logisticの非識別性の厳密証明と誤表示しない。
- W0のQ|XおよびM|XのGaussian条件付き分布を再導出。最終位置Xを初期手掛かりQとして置換しないことを確認。
- 設計§6の24ケースについて、Gauss–Hermite64対128の最大差は **2.8931190776404492e-11**。
- 同じ24ケースを、独立した方法である非心χ²の1次元積分でも点検。Gauss–Hermite128との差は最大 **4.996003610813204e-16**。設計した数値許容差に収まる。

最後の参照計算は、μ−tの二乗距離が `w² Var(M|X) × 非心χ²(df=2)` に従うことを使い、行動確率を1次元で積分したもの。NumPy 2.3.5 / SciPy 1.16.3 / Python 3.12.14環境で一時的なレビュー計算として実施。Phase 1dの実装コード・テストとして研究リポジトリへ追加したものではない。

この確認は予定式と許容差の妥当性を点検したもので、今後実装する§6の適応2次元積分との照合やG7全体を実施済みとするものではない。合成のAUC研究、500回bootstrap、実データ監査、既存201テストの再実行も今回行っていない。
