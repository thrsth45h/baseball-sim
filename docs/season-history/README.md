# 翌年への移行と年度別成績

[承認範囲と保存設計](../SEASON_HISTORY_DESIGN.md)

## APK

配布先は [GitHub Releases](https://github.com/thrsth45h/baseball-sim/releases/tag/android-v0.6-season-history-tech) の **Assets** にある `app-debug.apk`。PCサーバを必要とせず、Android端末に直接インストールする。CIで強制終了復旧を確認したAPKと同じファイルを添付する。[検証記録](VALIDATION.md)

バージョンは `0.6-season-history-tech`。前回のv0.5検証APKと署名が異なるため、Androidは同じアプリへの上書きインストールを受け付けない。既にインストールされている旧版のセーブを残す場合は、旧版を削除しない。

## 操作

1. ペナントで720試合を終え、球団ホームで **翌年へ進む** を選ぶ。
2. 確認画面で **進む** を選ぶと、同じ球団・選手・打順で翌年の初日が始まる。各選手の当年成績は0件から始まる。
3. 球団ホームで **年度別成績** を開き、年度を選ぶ。リーグや球団を切り替えて、その年の順位と打者イベント件数を確認できる。

手動セーブとロードは試合外の **設定・セーブ** から行う。ロードすると、保存時の年度とその分岐で確定していた過年度成績に戻る。別の打順でやり直した年の成績は、新しく進んだ分岐に結び付く。

## 対応範囲

新規ペナントと既存のv3保存は翌年移行に対応する。旧v1/v2保存は従来の単年度で続行できる。Roomの旧形式データ読取と、以前の別署名APKにAndroidが上書きインストールを許可するかどうかは別の条件となる。日程・試合ルール・仮の打者タイプはD062と同じ。年齢、成長、引退、編成の世代交代、オフの契約・補強は今後の設計で扱う。
