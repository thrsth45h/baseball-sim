# Androidの月間日程表

2026-11-25の本人指示「日程表を改修してください」と参考画像・[Pennant Spiritsの日程画面マニュアル](https://pennantspirits.ifdef.jp/manual_g_2.html)に基づく。参照元の月間把握と日別確認を、Androidの既存ナビゲーション・テーマ・球団名で実現する。

- 下部の「日程」を開くと、ゲーム内の当日を含む月を7列の日曜始まりで表示する。当日と選択日は区別する。年月、前月・翌月のボタン、月を直接選べる入口を設け、進行中の暦年の1〜12月を閲覧できる。日付は上部バーと同じ暦を使う。月を変えた初期選択は前の選択日を当月の末日までに丸めた日とし、同じ保存・表示基準日の範囲で回転やタブ往復でも閲覧位置を保持する。
- 日付のマスには自球団の対戦相手を短い球団名で表示する。確定済み試合には自球団から見た勝ち・負け・引き分け（○・●・△）と自球団側を先にした得点を表示する。未開始と進行中は確定した記号とスコアを表示しない。日付、正式球団名、状態、得点は読み上げで区別できるようにする。休養日とシーズン範囲外は対戦相手を表示しない。
- 日付を選ぶと、カレンダー直下に同日の全対戦カードを表示する。確定済みカードから既存の得点とイニング別結果を読み取り専用で開ける。休養日とシーズン外はそれぞれ判別できる案内を表示する。「日程」画面の日付・月・カードの選択は、投球・自動進行・保存を呼ばない。右上の既存「進行」ボタンは現行の操作を保つ。
- カレンダーは縦持ち320dpでも7列の横スクロールなしで閲覧できる。拡大文字や長い得点は必要に応じて日付枠内で段を増やす。既存のホームと上下バーの配色・書体を使い、参考作品の画像・ロゴ・背景は使用しない。

試合を指定日まで飛ばす新しい操作、停止条件、タイトル争い・注目選手、過去分の全投球ログの保存は別の仕様とする。既存の試合結果、日程、球団ID、乱数、セーブ形式を使う。

## 確認

3月の開幕日と翌月、日曜始まりの位置、休養日、シーズン範囲外、勝ち負け引き分け、ホームとビジターでの得点順を照合する。端末で月切替、日付タップ、確定したカードの詳細、回転、幅320dpと文字拡大、閲覧前後の保存トークン一致を確認する。検証済みAPKをGitHub Releasesに添付する。
