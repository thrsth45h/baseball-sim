# 打順・出場選手の試作版

[承認設計PR #50](https://github.com/thrsth45h/baseball-sim/pull/50)・[正本](../LINEUP_ROSTER_DESIGN.md)に基づくD061の限定実装。[実装PR #51](https://github.com/thrsth45h/baseball-sim/pull/51)は実装・CI・責任者の独立コード/成果物照合を完了し、最終統合待ち。マージ済みとはまだ扱わない。

## 操作

- 新シーズンは各球団12打者（出場9＋控え3）のv2で開始する。
- ホームの「打順・出場選手」から、上下の交換、控えとの交換を行う。「適用」まで試合・保存には反映されない。「変更を戻す」または画面の戻るで未確定編集を取り消せる。
- 編集は操作球団だけに適用する。他球団の選手閲覧は操作球団を変えない。設定から操作球団を変えても、以前編集した球団はその保存済み打順を使う。
- 試合中・一括進行中・停止状態・読込エラー時・シーズン終了後は編集できない。試合開始前に確定した両軍の出場者は、試合終了まで変わらない。
- 選手一覧/詳細の「n番」「控え」は現在の配置。確定試合の5件数は人物IDへ累積し、配置変更で以前の記録を付け替えない。
- 旧v1世界は108人の固定オーダーのまま継続できる。新規作成で自動変換はしない。手動slotは元の形式を保ち、ロードでその世界を復元する。試合中の手動save/loadは従来どおり不可。

人数は試作用で、製品の一二軍や登録人数ではない。全員同じ仮確率なので、打順/控えの選択による戦力差はまだない。投手・守備位置・途中交代・能力・年次・経営は含めない。
