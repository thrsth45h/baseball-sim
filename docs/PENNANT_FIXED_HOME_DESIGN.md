# 休養日のカード寸法と一体型順位表

2026-11-24の本人指示に基づくD064の表示変更。

- 休養日も試合日と同じ2グループ・全6行の枠を同じ寸法で表示する。行の高さ、左右幅、グループ間隔、順位表の開始位置をそろえる。休養日は枠内に一度だけ「休養日」と表示し、対戦相手、得点、試合への操作は出さない。「進行」1回で次の日に進む。
- セ・パの順位表は隙間なしの一つの枠にし、上部バーには「順位表」と「差」だけを表示する。前の指定どおり自リーグが左、他リーグが右。各行の順位、球団名、勝敗分、勝率、首位とのゲーム差は引き続き表示する。必要な列情報はアクセシビリティでも識別できるようにする。
- 順位表に横スクロールは設けない。通常幅では1行、幅や文字設定により読めない場合は各行を上下に分け、両リーグを同時に読めるよう左右に保つ。画面全体の縦スクロールを使う。
- 現在の順位画面と年度別の順位表も共通の表示にそろえる。保存・日付・試合順と試合結果は既存処理を使う。

## 確認

休養日・試合前・試合後の6行と順位表の開始位置を比較する。両リーグが左右にあること、バーの2ラベル、通常幅と320dp・文字1.5倍で横スクロールがなく、名前・勝率・差が収まることを実表示で確認する。日次進行と保存復旧を回帰確認し、同じ検証APKをGitHub Releasesに添付する。
