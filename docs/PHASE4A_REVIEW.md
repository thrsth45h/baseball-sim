# Phase 4a案の設計点検

2026-10-29 日本時間。[設計案](PHASE4A_DESIGN.md)と[ADR-0008](adr/0008-phase4a-count-reference.md)の承認前点検。責任者と読取り専用サブエージェントによる内部検討で、本人承認・外部査読・実装レビューではない。コード実装/旧研究変更は行っていない。

## 次工程の選択

仮の捕球確率・守備判断の追加、旧3b/3d接続と比較し、限定したカウントルールをゲーム側で検証する案を推奨した。未較正の係数を増やさず、将来どのモデルにも必要になる契約を具体化できる。ただし完全な1打席エンジンと称さない。

## 反例からの範囲設定

- 第三ストライクは常に打者アウトとは限らない。捕球済みと未捕球を区別し、今回は後者を拒否する。
- 通常の未捕球ファウル、合法ファウルチップ、未捕球ファウルバント、捕球ファウル飛球を同じイベントにしない。捕球されたバントのファウル飛球を三振へ変換しない。
- フェア打球の受渡し停止を「安打」「アウト」や「規則上の打席未終了」と読み替えない。
- カウント表は今回の8イベントの部分集合。投球時計や妨害/判定取消等を無視して完全な野球状態へ外挿しない。
- 同じfixtureを再生できても、発生確率・研究結果のゲーム採用・公式成績・製品セーブを検証したことにはならない。
- Python参照実装はAndroid言語やDBの採用ではない。96表/16列を言語非依存にし、研究repoと分離する。
