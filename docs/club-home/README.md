# 球団ホーム版の操作と範囲

[承認設計 PR #48](https://github.com/thrsth45h/baseball-sim/pull/48)・[設計書](../CLUB_HOME_DESIGN.md)に基づく限定UI。

新規起動ではペナントの球団ホームを表示する。シーズンがなければseedと操作球団を選び「新シーズン」を押す。既存の「1試合」モードは上部から切り替えられ、OSが復元したモード選択を尊重する。

- ホームから選手一覧、日程、順位、記録、設定・セーブへ移動する。
- 選手一覧では閲覧球団を選び、固定9人のIDを押すと詳細が開く。詳細から戻ると同じ一覧位置に戻る。球団閲覧は操作球団を変えない。
- 「試合を見る」は公開済み試合の表示だけを開く。「自球団戦へ進む」は既存の進行操作を実行する。試合画面で1球、1打席、最後までを選ぶ。
- 新シーズン、操作球団の変更、手動セーブ・ロードは設定画面で行う。手動保存は試合外に限る。
- 一括進行中は全ページの上部に停止予約を表示する。閲覧中も進行は同じViewModelが所有する。

選手は既存の固定108 ID・所属・固定打順と、確定した完了試合の5件数だけを表示する。セーフ安打には本塁打を含む。人名、年齢、能力、守備位置、公式打率、編成・経営・次年度を追加したものではない。

同じworld/generation内では画面選択を保ち、revision更新で件数が更新される。新シーズンや手動ロードでworld/generationが変わればホームへ戻る。OSの保存可能UI状態を利用するが、force-stop後に最後の選手画面を永久保持する保証はない。

APKと検証結果は[検証記録](VALIDATION.md)を参照。ユーザーPCでSDKやエミュレータを起動せず、Android検証は隔離CIで行う。
