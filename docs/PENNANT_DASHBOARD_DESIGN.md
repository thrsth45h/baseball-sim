# ペナントのメイン画面と下部ナビゲーション

保留する当日のスコア表示、上部バー、自球団カードの動作は[上部バーと当日の進行](PENNANT_DAY_FLOW_DESIGN.md)が最新。

2026-11-23。D060の画面構成を、ユーザーの「メイン画面こんな感じ+ボトムナビゲーション」と添付のPennant Spirits画面に沿って更新する。既存ペナントの表示・操作への入口を整理する。試合ルールおよび保存や進行の契約はD057/D058/D060〜D063を参照する。

## メイン画面

- 最初に操作球団、現在の週と曜日、対象セーブで表示できる年度、順位・勝敗を読み取れる構成にする。日付は今の試作日程の週・曜日で表示する。
- 進行中は「1日進める」を主要操作とする。「自球団戦へ進む」「シーズン終了まで」「試合を見る」はそれぞれ既存の操作として使える。休養日、進行中、停止予約、エラー、完走後の「翌年へ進む」を現行条件に従って表示する。
- 同じ画面で当日カードを両リーグ分確認できる。操作球団の試合を強調し、対戦相手、確定スコア、試合前／進行中の状態を公開済みデータから表示する。休養日には試合がないと分かる表示にする。カードの閲覧で試合は始まらない。
- 操作球団の所属リーグの順位をホームで見られるようにする。全リーグの順位、個人記録、年度別成績は「成績」から開く。狭い縦画面は縦に並べ、横幅に余裕があるときは当日カードと順位を並べて表示できる。

## 下部ナビゲーション

| タブ | 入口 |
|---|---|
| ホーム | 操作球団・現在の状況・試合進行 |
| 日程 | 既存の前日・翌日閲覧と当日の対戦・結果 |
| 編成 | 打順・出場選手、選手一覧と詳細 |
| 成績 | 順位、個人成績、保存済み年度の成績 |
| 設定 | 操作球団、新シーズン、セーブ・ロード |

スクロールしても手の届く位置に下部ナビゲーションを表示する。最初のペナントを作る前は開始操作を見せる。試合を見る入口と単独1試合モードを保持する。画面の選択は保存先の世界と世代に結び付けて復元し、選手詳細からは一覧へ戻る。タブ切替、スクロール、選手や日程の閲覧は進行・保存・操作球団の変更を発生させない。

PC画面の情報構成を参考に、架空球団の表示とAndroid向けのカード・ナビゲーションで設計する。既存画面の階層を増やしすぎず、データや操作が存在する入口を出す。検索・人事・球場・実暦・戦力などの表示には今後の仕様が必要になる。

## 検証

現行の画面遷移・保存・復旧・年度移行を回帰確認する。新しいホームが試合日・休養日・試合中・完了状態を公開済みデータから表示すること、5タブと既存の入口に到達できること、閲覧や画面回転に伴う書き込みがないことを確認する。隔離エミュレータで幅の狭い縦画面を点検し、実装PRを独立レビュー後に統合する。検証APKは[既存の配布手順](APK_RELEASES.md)に沿ってGitHub Releasesに添付する。
