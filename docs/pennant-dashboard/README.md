# ペナントのホームと下部ナビゲーション

[画面設計](../PENNANT_DASHBOARD_DESIGN.md)・[実装PR #58](https://github.com/thrsth45h/baseball-sim/pull/58)

## 操作

ホームには操作球団の成績と現在の週、当日の対戦カード、所属リーグの順位が表示されます。「1日進める」で日程を進め、必要に応じて自球団戦へ移動できます。完走済みの対応セーブでは「翌年へ進む」が表示されます。

- **日程**から前日・翌日の対戦を確認できます。
- **編成**から打順と出場選手を変更し、選手一覧と詳細を開けます。旧固定オーダーでは選手情報を閲覧できます。
- **成績**から順位と個人成績を確認できます。完了年があるセーブでは年度別成績を閲覧できます。
- **設定**から操作球団や新シーズンを選べます。試合外では手動セーブ・ロードも使えます。

下部のタブは内容をスクロールしても画面に残ります。単独の「1試合」は画面上部から選択できます。
