## 操作

上部バーの左に操作球団の名前、リーグ内の順位と勝敗分が表示されます。年月日と曜日は、右の「進行」の左にあります。最初の試合は2026年3月27日（金）です。初期画面の3月26日（木）は休養日です。

「進行」を押すと、その日の全スコアが同時に表示されます。「翌日へ」で次の日の試合前に切り替わります。休養日は一度で進みます。最終日はスコアを確認してから「終了画面へ」を押すと、対応セーブで「翌年へ」を選べます。

最上段のカードは自球団の試合です。タップするとその試合の開始画面、進行中の試合、または確定結果を開きます。順位表は左が自リーグ、右がもう一方です。狭い画面では表を横にスクロールできます。

- **日程**から前日・翌日の対戦を確認できます。
- **編成**から打順と出場選手を変更し、選手一覧と詳細を開けます。旧固定オーダーでは選手情報を閲覧できます。
- **成績**から順位と個人成績を確認できます。完了年があるセーブでは年度別成績を閲覧できます。
- **設定**から操作球団や新シーズンを選べます。試合外では手動セーブ・ロードも使えます。単独の「1試合」もここから開けます。

上部バーと下部のタブは、内容をスクロールしても画面に残ります。
