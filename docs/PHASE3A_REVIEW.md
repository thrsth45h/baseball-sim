# Phase 3a設計の点検記録

2026-10-28。対象 `phase3a-design-v0.1`。責任者による点検と、別サブエージェントによる読み取り専用の設計批判。実装の独立コードレビューやユーザーの仕様承認ではない。研究値の新規読取り・学習・実装は行っていない。

## 修正して提案へ含めた点

1. **母集団を限定**: 「無条件の全打球」とせず、登録R・hit_into_play・数値適格に条件付けた記録集合と定義。守備後の記録への選択があるため全接触へ直結させない。旧processedの位置等の制限は新対象へ継承せず、別母集団だと明記。
2. **年度の順序**: 全145実ファイルの確認をfit前に行う案は、未来ファイル非読取りと衝突する。D6の固定manifest hashで集合を定義し、2023の実体確認→fit凍結→2024/2025の実体確認と評価へ分けた。
3. **平滑化の意味**: 一様なセル擬似度数は非一様独立表で依存を作る場合がある。各軸独立のepsilon混合を採用案とし、同じ周辺と経験的独立表での同値を保つ。数理恒等式を別担当も確認。
4. **平滑化の反例**: 固定epsilon0.01は標本増加で消えず、希少区分の周辺確率を相対的に増やす。研究上の仮定として開示し、結果を見て調整しない。能力・物理誤差とは対応させない。
5. **年度差の解釈**: 対象到達率と欠損・変換不能・非有限・範囲外を報告。表が揃っても欠損の無作為性は証明されない。既閲覧2025を未使用holdoutとしない。
6. **評価の対象**: 72確率の解析的カテゴリ損失を使い、連続密度・単発抽選を評価確率としない。試合bootstrapは損失総和/球数総和で対応を保ち、学習固定の区間に限る。J1が悪ければ真の独立とは言えない。
7. **指標と価値を絞る**: 全行に同じ確率を返すため二値ECE/AUCを追加せず、セルの割合・TVを補助にする。周辺指標は両モデルで同値であり、独立の改善証拠と数えない。能力発見よりも後の比較基準が目的。
8. **区分の限界**: 連続値・セル内分布・方向を生成せず、95mphやBarrel等を正確に再現したとは扱わない。値付きraw全体の正式監査・物理品質保証・バント完全抽出にも拡張しない。

## 実際に確認したこと

- 両リポジトリの作業状態clean・最新main、未マージPR0を確認。既存変更を上書きしない専用設計ブランチを作成。
- 既存3manifestの生バイトhashがD6 inventoryと一致。宣言は47/49/49件、720684/711899/712528行、空登録0/1/1件。これは登録宣言の確認で、145実体の全値検査ではない。
- 人工の非一様独立表と依存表を使い、平滑化後の和1・正値・恒等式を確認した。和と恒等式の誤差は1e-12以内。MLBの性能計算ではない。
- 公式CSV文書で一部未追跡打球の推定EV/LAを確認。hc_x/yの記述だけから初期の物理方向を確定したとは扱わず、今回のモデルへ追加しない。

## 残る判断

別担当は、限定した分布研究として成立し、epsilon案は目的に適すると評価した。一方、全接触・守備前の物理生成・能力効果への接続は未解決。2024を省く最小案も可能だが、今回は候補調整に使わない年度診断として残す。

この点検は採用承認を代行しない。ユーザーへ研究対象・入力拡大・実装開始の承認を求める。合格条件は固定比較の正しい完了であり、期待する方向の結果が出ることではない。

完成した設計・本点検記録・ADRを別担当が再読し、数式・年度順序・母集団・到達率・評価・公開範囲に重大な矛盾がないことを確認した。追加した人工抽選の度数試験も研究性能ではなく実装受入れの確認として扱う。
