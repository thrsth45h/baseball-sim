# ペナントホームの表示整理と2026年の日付

2026-11-24の本人指示に基づくAndroid検証版の画面変更。上下の固定バー、自球団カード、右上の二段階進行を使う。

- 左上に操作球団名・順位・勝敗分、進行ボタンの左に「2026年3月27日（金）」形式の日付を表示する。年目・週番号を外す。日程タブも同じ暦日を使う。最初の試合は2026年3月27日、既存の先頭休養日は3月26日。翌年以降は各年3月27日を起点に既存の日番号を暦へ写し、曜日は実際の日付から得る。開幕日の参考は[NPBの2026年日程](https://npb.jp/event/2026/)。
- ホームから試合消化数・seed・直近の試合・シーズン終了まで・「当日の試合」およびリーグ1/2の見出しを外す。日次進行中の停止予約を表示せず、連打を防ぐ。
- 試合日の「進行」で当日の全試合結果と更新後の成績を同時に表示し、「翌日へ」で次の日付に切り替える。通常進行中は途中スコアと途中成績を表示しない。失敗時は既存のエラーと保存済み状態から再開する。休養日と最終日の進行・翌年開始は従来の意味を保つ。
- 操作球団カードを最上段に固定し、同じリーグの残り2試合、他リーグの3試合の順に表示する。カードを開く際は試合IDと既存確定順を使う。試合前後でカードの寸法を統一し、文字拡大時も得点表示によってカード位置が動かないようにする。
- ホームと現在の順位画面は自リーグを左、他リーグを右に並べる。列は順位・球団名・勝敗分・勝率・ゲーム差。既存の同率順位を使用し、勝率は勝数÷（勝数＋敗数）を小数3桁で表示する（.500、1.000）。ゲーム差は首位との（首位勝数−当該勝数＋当該敗数−首位敗数）÷2。首位や比較できない場合は「—」を表示する。狭くて読めない場合は左右の並びを保ち横スクロールで閲覧できる。
- Androidの球団表示は、L1のT01〜T06を読売、阪神、横浜DeNA、広島東洋、東京ヤクルト、中日、L2を福岡ソフトバンク、北海道日本ハム、オリックス、東北楽天、千葉ロッテ、埼玉西武に対応させる。広い画面では[NPBの球団名](https://npb.jp/bis/teams/)を使え、順位と対戦カードでは短縮表記を使える。球団ID・選手ID・合成日程・乱数・保存形式はそのまま使う。ロゴ、実在選手、公式カードの取り込みは対象外。先の架空球団方針に対し、今回明示された変更範囲は検証版の画面に適用する。

## 検証

両リーグを選んだ際のカード順と順位表、試合前・処理中・終了後のスコアと寸法、次の日付、既存試合への到達をエミュレータで検証する。勝率・ゲーム差、休養日・曜日・年切替を単体確認する。既存の停止・シーズンスキップの内部契約、試合結果、旧セーブ復旧を回帰確認し、検証したAPKをGitHub Releasesに添付する。
