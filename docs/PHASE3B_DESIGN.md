## 1. 相談する範囲

**数値のある打球記録について、粗い区分の割合を揃えたまま、その中を5mph・5度刻みで扱う効果を比較する。抽選結果として具体的な速度・角度も返す研究用プロトタイプを作る。**

例えば「90〜100mph」という区分だけでなく「97.2mph、18.4度」のような数値を返す。ただし、5単位の区分内を一様に埋める部分は仮定であり、その小数桁まで実測の精度を再現したとは扱わない。

対象はPhase 3aと同じ限定記録集合。新規データ取得、全接触への外挿、左右方向、物理フェア／ファウル、飛距離、守備・走塁、安打・得点、打者能力1〜20、ゲーム統合は含めない。記録上のhit_into_playを先に抽選するゲーム契約も作らない。旧研究のコード・モデル・結果・推論契約・凍結文書・hash索引を保存する。

## 2. 現状・根拠と代替案

Phase 3aは、同じ周辺を持つ独立J0／同時J1を72区分で比較した。区分内の分布は学習・生成していない。次の比較でJ0/J1を連続密度へ同じ形で拡張するだけなら、対数損失の差は既存の差と同じになり、新しい改善の証拠にはならない。

また、公開済み2023表ではEV≥120mphが1/123,886件なのに対し、固定epsilon0.01のJ1は同区分へ約0.00111910、学習件数換算で約139件の確率を与える。これは[既存設計に明示された平滑化](PHASE3A_DESIGN.md)の性質で、旧結果の計算誤りではない。数値生成へ無条件に引き継がない。[固定された2023集計・モデル](https://github.com/thrsth45h/statcast-swing-model-v1/blob/c155a6c0af899f2946dbcc4292c680a121fe781b/reports/phase3a/real-03/fit/model.json)

| 案 | 評価と今回の提案 |
|---|---|
| A: 粗区分と細区分のヒストグラムを同じ支持域・粗区分確率で比較し、区分内を仮定で数値化 | 集計だけで実装・独立検算ができる。区分内情報の追加効果と数値抽選の契約を切り分けられる。推奨 |
| B: 既存J0/J1のセル内だけ同じ連続密度にする | 組合せの効果の再計算になりやすい。区分内の改善を新たに検証できない |
| C: 二変量KDEや柔軟な密度モデル | 滑らかな分布にできるが、帯域・境界・記録の丸め・計算量の追加設計が必要。今回の最小比較では保留 |
| D: EV≥120を除く、または任意の上限へ切り詰める | 尾部仮定を避けられるが、母集団変更・未知の真の上限・境界への集中を導入する。今回は行わない |

Aも物理生成の完成ではない。5単位内の形、120mph以上の速度の形は未検証の研究仮定で、主比較の成功によって正当化されない。

## 3. 対象・入力・年度の順序

Phase 3aと同じ、承認対象raw登録集合のR試合、descriptionがhit_into_play、EV/LAが両有限、EV≥0、−90≤LA≤90の行を使う。旧processedの適格条件は継承しない。記録バントの自動除外や欠損の補完、実値のclipはしない。除外は欠損→変換不能→非有限→有限範囲外の排他的な順。

Savant公式文書ではEV/LAに一部未追跡打球の推定値が含まれる。有限値をすべて直接測定・潜在的な真値とは呼ばない。[CSV文書](https://baseballsavant.mlb.com/csv-docs) EVの単位はmph、LAは度。[EV](https://www.mlb.com/glossary/statcast/exit-velocity)、[LA](https://www.mlb.com/glossary/statcast/launch-angle)

[Phase 3a §4](PHASE3A_DESIGN.md)と同じ固定manifest集合・hash・必要9列・照合規則を継承する。登録は2023が47、2024/2025が各49、計145。manifest登録以外の探索・追加取得はしない。各年の実manifest・全登録のhash/行数/schema・空登録・キーの正値整数/欠損/重複・日付/年度/Rを照合し、不一致は停止する。原入力は読取り専用。glob、都合のよい重複除去、入力修正や一部chunkを捨てた継続は不可。

1. **2023だけ照合・fit**。47登録から900セルの件数を得る。N=0は停止。fitは2024/2025の実manifest・metadata・Parquet・header・値・hashを開かない。既存の静的な登録宣言は利用可能。
2. **凍結**。設計版、支持域・全境界・全仮設定・モデル名/順、2023入力同一性、集計、モデル、使用するプロジェクト内ソースすべてと依存版を結合する。
3. **2024診断・2025比較**。年度ごとに49登録を照合する。2023の入力・凍結を再確認し、年度間game_pk/投球キー重複を拒否する。必要な2023キー列の再読取りは可、再fitは不可。2024でモデル・区分・係数を選び直さない。

本案は公開済みのPhase 3a集計・結果を踏まえた後続設計である。2024/2025は既閲覧で、独立した未使用holdout・前向き検証とは呼ばない。

## 4. 固定する区分と基底分布

細区分Fは以下の900セル。EVを外側、LAを内側として平坦化する。

- EV下端: `[0,5,10,...,115,120]` mphの25区分。有限区分は下端を含み上端を含まない。最後は[120,∞)。
- LA境界: `[-90,-85,...,85,90]` 度の36区分。下端を含み上端を含まない。最後の[85,90]だけ90も含む。
- 粗区分CはPhase 3aのEV9×LA8の72区分。その境界はすべて細区分の境界に一致する。

全域で積分1の基底分布Bを研究用に固定する。

```text
B(v,a) = b(v) / 180,                  v >= 0, -90 <= a <= 90
b(v)   = 1/125,                       0 <= v < 120
       = exp(-(v-120)/5) / 125,        v >= 120
```

EVの積分は120/125+5/125=1。EV≥120の基底質量は1/25、各細セルの基底質量w_fは1/900である。基底全体をMLBの打球分布とは解釈しない。後述する**全分布で合計1件相当**の擬似度数と、セル内の補間にだけ使う。

尾部の指数分布の尺度τ=5mph、有限セル内の一様性、5単位の刻み、合計擬似度数α=1は**未較正の研究仮設定**。測定誤差・選手能力・物理上限の推定ではない。EV上限を設けず、負の速度や範囲外角度も生成しない。

## 5. H0/H1と同じ粗区分確率

2023の細セル件数n_f、全件数N、粗セルCの細セル数m_Cと件数n_C=Σ_(f∈C)n_fを使う。

```text
H1: p1_f = (n_f + 1/900) / (N+1)
粗区分確率 q_C = (n_C + m_C/900) / (N+1)
H0: p0_f = q_C / m_C,                 f belongs to C
```

H0は粗セル内のB条件付き分布、H1は細セル内のB条件付き分布を使う。どちらも900確率は正で合計1。同じ粗セルへ戻すとΣp0_f=Σp1_f=q_Cが厳密に成立する。H0/H1の違いは、粗セル内で速度・角度の細分布を学習するかどうかである。細かい周辺分布と細かい組合せの両方が変わるため、改善を「細かい相関だけの効果」とは帰属しない。

粗セルの質量の違いは比較から除かれるが、α=1はH1のセル内推定にも影響する。平滑化の影響をすべて除いた純粋な解像度の実験とは呼ばず、固定した二つの推定法を比較する。

**H0は旧J1ではない。** Phase 3aのepsilon0.01を置き換える新規の比較基準であり、旧72確率・指標を変更しない。900カテゴリの損失を旧72カテゴリの損失と直接比べない。

この擬似度数の影響はNとともに消える。2023の公開済みEV≥120件数1なら、新しい両モデルの同区分確率は(1+1/25)/(123886+1)、学習件数換算で約1.04件となる。これは性能の事前保証ではない。α=1は弱い平滑化で、少数の観測セルへ集中し、空セルの予測確率が非常に小さくなる場合がある。H1の悪化も有効な結果として残す。

数値密度は、選んだ細セル内でBを正規化したものをp0_fまたはp1_f倍する。有限EV/LAはその細区分の一様分布、EV最終区分は120+Exponential(scale=5)、LAは該当5度の一様分布となる。支持域・積分と900確率の一致を検査する。

## 6. 評価と解釈

**唯一の主比較は既閲覧2025の900カテゴリLog Loss差H1−H0。負ほどH1が良い。** 自然対数を用い、各対象行の解析的p_fの損失を平均する。clipや乱数による予測確率の近似はしない。

同じ細セルでは両密度に共通の条件付きBが掛かるので、密度対数損失の差もこの差と一致する。しかし評価対象は記録値の900カテゴリである。丸め・測定誤差の観測モデルや、小数値の潜在的な真の連続密度を検証したとは呼ばない。**有限5単位セル内の一様性も尾部尺度τも、この主比較では検証できない。**

- 各年・両モデルの900カテゴリLog Loss、Brier総和（900で割らない）、900セルの観測/予測/差、TV、EV/LAの細区分周辺TVを保存する。
- 粗72セルへ集約した両モデルの一致、観測との差、900セルの非空/空数を保存する。H1の粗セル損失改善を主張しない。
- EV≥95/110/120/125/130/140mphの記録件数・割合と解析的予測割合を診断として示す。120以上の予測は両モデルで同じq_tail×exp(-(t-120)/5)。尾部の少数例から指数形・物理的妥当性を認定せず、年度診断でτを変更しない。
- EV<120とEV≥120に分けた件数、各モデルの損失総和/条件付き平均、主差への寄与（当該行の損失差総和/全体N）を出す。空集合の条件付き平均はnull、全体への寄与は0。2023尾部の1件からH1がLAの5度セルにも集中し得るため、尾部角度を学習成功と解釈しない。内訳で候補選択・後付けの除外・追加の有意差主張をしない。
- 2025主差だけに、対象のあるgame_pk昇順・対応付き500回試合bootstrapを付ける。PCG64(20261028)、G試合からintegersでG回復元抽選、損失総和/対象数総和、linear補間の.025/.975分位。G<2・無効反復は理由付きnull、再抽選なし。固定学習の条件付き区間で、再学習や将来年度全体の不確実性は含まない。
- 評価対象が空なら指標null・理由付き。H1の勝利・有意差を完了条件や製品採用の根拠にしない。2024は診断だけで候補選択・再較正はしない。

## 7. 数値抽選と再現性

推論は凍結モデル、H0/H1の指定、件数、明示Generator(PCG64)だけを受け取り、EV(mph)/LA(度)の数値ペアを返す。個票、実測ペア、description/events、打者ID、ヒット/アウト、真の能力を入力しない。

1抽選につき3個の一様乱数を固定順に使用する。1個目でEV-majorの900確率のCDF逆変換、2個目でEVセル内、3個目でLAセル内を抽選する。`random((n,3))`相当の行順で乱数を消費し、一括と分割・状態保存復帰で同じ列が続く。尾部は`120-5*log1p(-u)`。有限区分の浮動小数丸めで開上端に一致するときだけ、その区分内の直前の表現可能値へ戻し、実測値のclipと区別する。

公開例は各100,000抽選、H0 seed=20261029、H1 seed=20261030。900区分度数・粗72集計・閾値件数・要約統計・開始/終了RNG状態を保存し、数値ペア自体はGitへ入れない。元実測ペアの抽出・再配布は行わない。数値生成が完成しても、全接触や架空打者の生成器として採用しない。

## 8. worker実装・受入れと独立レビュー

本人承認・設計マージ後、研究側の新規`baseball_calibration.phase3b`・専用テスト・`reports/phase3b`/`data/phase3b`だけの新規出力をworkerへ委任する。既存モジュールは読取り利用可、旧ファイルを変更しない。root README案内のみ例外。依存版は維持する。

CLIはsynthetic smoke、2023 fit、凍結後evaluate、数値sampleを分ける。smokeは実入力を開かず、synthetic/非実学習と表示し、実データ成果物へ流用しない。新規出力先のみ許可し、入力との重なり・既存出力への上書き・途中キャッシュからの再開を拒否する。chunk処理、各工程30分・peak RSS 2GiBを停止目安とし、超過を成功扱いで隠さない。

必要な検証:

1. 境界0/5/95/115/120、LA−90/−85/85/90、非有限・範囲外、900→72の全セル対応と除外分母。各年のNと粗72セルの実件数が固定されたPhase 3a集計と一致することも確認する。2023 fitでは2023の公開参照だけ、後続年度の参照は凍結後のevaluateで使い、未来年度の参照をfitに混ぜない。
2. 全確率正・合計1、粗セル集約一致、粗セル内一様件数ならH0=H1、非一様なら差が出る例。独立表ならH0=H1という旧J0/J1の条件を流用しない。
3. Bの積分1、有限セル・開尾部の確率/密度/CDF整合、95/120/125等の閾値、別式・数値積分による照合。尾部0件の人工例でも正値・正規化。
4. 保存n_f/Nと固定規約から両確率・粗集約を閉形式で照合。整合hash付きモデル名入替え・確率改変・件数/N変更も拒否する。evaluateのraw再fitで改変を隠さない。
5. fitが将来年度を開かない、evaluateが再fitしない、モデルの後日改変や入力不一致・年度間重複を拒否する。情報漏洩防止を実ファイルアクセスの監視でも確認。
6. 同seed同値、分割抽選・状態保存復帰の完全一致、極端な一様乱数で支持域を守る、数値を再区分した度数と生成確率が整合する人工例。旧推論契約・既存全テストの回帰。

fitはplan/model/input-identity/cohort-audit/freeze、evaluateは評価・入力同一性・監査・報告、sampleは集計とRNG状態を保存し、各工程にhashと実行資源記録を付ける。公開は集計・係数・入力識別・手順のみ。個人絶対パス、自由記述、個票・ID・実測数値ペア、生データ、大規模生成物は入れない。実入力生バイトhashと、公開参照の改行差の処理を区別する。

workerは別出力先で2回実行し、数値・モデル・入力同一性の一致を確認する。責任者はコード・テスト・実行・別式の期待値・旧成果物非変更を独立点検し、修正はworkerへ直接依頼する。時間・資源の記録は決定的な成果物と分ける。
