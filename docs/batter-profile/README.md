# 打者の試作用タイプ版

承認済みのD062に基づき、新規シーズンに打者の試作用タイプを加えたAndroid技術検証版。[設計PR #52](https://github.com/thrsth45h/baseball-sim/pull/52)・[設計の正本](../BATTER_PROFILE_DESIGN.md)・[実装PR #53](https://github.com/thrsth45h/baseball-sim/pull/53)

## 操作

- 新シーズンは各球団12打者（出場9＋控え3）のv3で開始する。
- 編成・選手一覧/詳細に「標準・ミート型・長打型」の試作用タイプを表示する。タイプは人物に固定され、編集や成長は行わない。
- ホームの「打順・出場選手」から上下移動や控え交換を行い、「適用」で保存する。未適用の編集は試合・保存へ反映せず、戻ると破棄する。
- 試合開始時に両軍の出場者とタイプを固定する。1球・1打席・試合終了までの操作と日程スキップは同じ逐球生成を使う。
- 個人の既存5件数は試合の実イベントから集計する。セーフ安打件数には本塁打を含む。
- 旧v1は108人固定、旧v2は144人で打順編集可能のまま、元の同一仮確率を維持する。既存セーブを自動変換しない。手動保存先は従来の1枠。

三タイプの整数表は未較正の仮設定で、正式能力1〜20・選球眼や積極性・研究モデルの採用ではない。最適打順やタイプ間の強さの均衡も未検証。投手・途中交代・一二軍・成長・年次・経営は今回追加していない。
