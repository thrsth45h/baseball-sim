# ADR-0017: Pennant Spiritsをゲーム全体の主な設計基準にする

- Status: **Accepted**（2026-11-17、主基準と完成像のみ）
- 関連決定: D059 CONFIRMED。D029/D030/D031/D056 OPENを維持。
- 正本: [基準・機能対応表・開発順序](../PENNANT_SPIRITS_BASELINE.md)
- 明示承認: 本人がPC版Pennant Spiritsをベースにしたいと述べ公式マニュアル21ページを提示。責任者が年間の球団運営と本作の既定方針を重ねる整理を提示した後、本人が「はい」と回答。

## 現状と問題

main `9e0f4b513d935af2479fd500967f2cb884858551`で、単年度の限定ペナント/観戦/限定件数/保存復旧のAPKまで完成。これまで複数作品を参考にしていたが、利用者が目指す球団運営全体の具体的な主基準が明文化されていなかった。編成・育成・契約・世代交代・翌年は未実装で、基盤検証の進捗を完成ゲームと混同しない整理が必要。

## 選択肢と採用理由

- A（採用）: Pennant Spiritsを機能構成と年間の遊び方の主基準にし、Android/1〜20能力/内部1球/無期限/手動と委任等の本作の方針を重ねる。
- B: 複数作品を並列の参考に留める。自由度はあるが、本人の希望に対する完成像と優先順位が曖昧になる。
- C: 参照作品の規約・数値・PC操作まで一括で採る。明確に見えるが、本作の能力尺度/研究/Android操作等と競合し、未検証の計算式や調整値も確定扱いになる。

本人の希望を完成像の軸に置くAを採用。機能の主基準を持つことと、全細目を同一にすることは区別する。マニュアルだけでは内部計算やバランスの妥当性は検証できず、本作の能力/公式記録/CPU/年次/保存等の設計作業は残る。

## 影響と確認方法

README/GAME_DESIGNの参考作品の優先順位、台帳、ROADMAP、HANDOFFを更新し、21ページの機能対応表と利用者向けの段階目標を記録する。ゲーム/研究コード、既存の確率・日程・記録・セーブ・APKは変更しない。文書リンクと既存決定との整合、未実装を実装済みとしていないことを点検する。

## 承認範囲と未解決事項

Acceptedは主基準・完成像・既定方針の維持のみ。正本のA〜Dの工程案、次の球団ホーム/選手一覧・詳細の画面仕様、規約や内部モデル、実装開始は未承認。詳細を整理してから別設計として判断する。新しい重要判断は本人へ戻し、同じ承認範囲の通常判断を繰り返し確認しない。
