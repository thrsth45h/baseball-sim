# ADR-0002: Phase 2の初回研究を通常スイングの接触予測に限定する

- Status: **Proposed**
- 設計PR: 本ADRと[Phase 2a設計](../PHASE2A_DESIGN.md)を含むPR。
- 関連決定: D007、D022–D025、D028（PROVISIONAL）、D029（OPEN）。確定性を変更しない。
- ユーザー承認: Phase 2へ進む方向は確認済み。**詳細仕様と実装開始は未承認**。
- 対象: `phase2a-design-v0.1`、研究側main `4bf94dee60de9e33cfd7f16e7439cac34a36a6fc`。

## 現状と問題

Phase 1dの合成研究と限定したD6実データ監査は完了した。真正な期限前観測・主観的知覚や、MLB向け潜在知覚モデルは未検証。これを既知の能力として扱わず、次の物理的な段階である接触を独立して調べる。

## 比較した案

- A: 通常スイングの接触／空振り予測を先に作り、通常ファウル・ファウルチップ・インプレーは別タグとして保存。
- B: 初回から4クラスの分岐モデルを実装。
- C: 打席全体や選球眼のMLBへの自由適合まで同時実装。

## 推奨理由・反証・トレードオフ

Aは観測されたスイングだけで対象を固定でき、小さな基準モデルと接触残差を比較できる。接触だけでは三振回避や試合生成は完成せず、結果タグの先の分岐が別途必要という制約を明示する。

Bは1球の結果に近いが、接触と希少な結果分岐を同時に解く必要がある。Cは現在の情報境界・未検証の配球/判定/能力尺度を混ぜるため今回は見送る。

## 事実と研究上の仮定

対象descriptionと既存適格性は研究側の保存された定義・入力へ対応する。公開CSVの結果ラベルを、映像等で独立に検証した接触真値とは呼ばない。接触と三振回避能力は同義ではない。

C0/C1/C2、penalty、50球、候補選択、数値許容差・資源上限は本研究の仮設定。実選手の認知能力・公開能力の実測係数ではない。C2はC1を固定した打者別の予測残差であり、未知・小標本をC1へ厳密に戻す。

## 影響と検証

新規phase2aモジュール・テスト・集計を研究側へ追加する案。旧研究・推論契約・依存設定・ゲーム/Android/セーブ形式を変更しない。実データの学習は2023、候補選択は2024、既閲覧の2025は凍結後の再現比較とする。

P2-G1〜G8でラベル、情報境界、C2残差の解、未知打者、分割・凍結、数値・クラスタ区間、再現性・入力照合、既存非変更を検査する。望む予測改善を工学的な完成条件にしない。

## 判断を求める内容

ユーザーには、二値の接触予測と4タグの保持、C0/C1/C2の比較、2023/2024/2025の役割、旧研究保存、ゲーム採用・能力較正を含めない範囲を提示し、詳細仕様と研究実装開始の承認を求める。承認後に責任者がworkerへ直接委任し、完了後に独立レビューする。

公開能力との対応、Phase 2bの結果分岐、打席全体への結合、商用利用・派生物の権利は別の判断として残す。
