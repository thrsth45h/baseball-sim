# ADR-0001: Phase 1dを固定課題の識別検証と実データ接続の監査に限定する

- Status: **Proposed**
- 文書日: 2026-10-28（日本時間）
- 関連Issue: なし。小規模な研究範囲の提案として設計PRを入口にする。
- 設計PR: 本ADRと [PHASE1D_DESIGN.md](../PHASE1D_DESIGN.md) を追加するPR。
- 関連DECISIONS: D006–D008、D022–D025、D028（PROVISIONAL）、D029（OPEN）。変更なし。
- ユーザーの依頼: 「1dを固めて」。設計の具体化依頼として記録。
- 研究範囲の採用・実装開始・PRマージ・製品採用の承認: **未記録**。
- 対象フェーズ: Phase 1d。実装は別の開発用Codexが研究リポジトリで担当する案。

## 現状と問題

Phase 1bの条件付き行動予測とPhase 1cの合成行動生成は研究として保存済みだが、認知的な選球眼の測定や能力1〜20の換算は未検証。Phase 1cでは知覚分散の定数項が全体率にも作用し、生成器と推論器が同じ仮定を共有している。単一の知覚抽選の確率を、そのまま実データの予測確率として比較できない。

## 比較した案

1. 直ちにStatcastで自由なr/a/誤差/温度を推定する。適合値を得るのは早いが、機構・尺度の識別と観測の時間境界が未解決。
2. 分散項を削除して新方式にする。現行の固定r・等分散条件ではスコア順位が同じで、課題の識別改善の説明にならない。
3. **推奨案:** 合成の固定課題で作用・同率比較・反例・誤特定を検証し、周辺確率と実データ接続条件を定義する。
4. 独立認知データの確保まで全工程を止める。研究の主張を限定して進める代替経路があるため、現段階では推奨しない。

## 提案する決定

Phase 1dは、生成条件と推論仮定を分離した合成研究、主要ΔAUC比較、同率条件の副次比較、7つの固定世界、識別不能な反例、Gaussian世界の周辺確率の参照検証、入力情報と将来のM0/M1/M2比較契約を対象とする。

MLBへの学習、新規データ取得、能力係数の推定・確定、期待得点・接触・打球、ゲーム統合は含めない。既存M0/M1/M2・通年報告・Phase 1cを変更しない。全ての標本数・ストレス係数・許容差は研究プロトコル上の仮設定として版管理する。

詳細な数式・標本・乱数・受け入れ条件・停止条件は [設計書](../PHASE1D_DESIGN.md) を正本とする。本ADRに数値を重複して記載せず、将来の変更は設計書と承認範囲の差分でレビューする。

## 根拠とトレードオフ

小さな反証可能な工程に限定し、合成上の作用分離を現実の心理的識別へ昇格させない。結果が否定的でも研究を完了できる。一方、この工程だけでは実選手の能力値・得点価値・Android性能の妥当性は確認できない。

## 既存仕様・実装・セーブへの影響

既存の公開4技能・積極性の区分・1球単位の構造を維持。D029をOPENのまま保持。本PRは文書だけで、実行コード・研究結果・ゲームのセーブ・APIへ変更を与えない。

## 受け入れ基準・将来の検証

設計書のG1〜G10を満たすことが研究実装の工学的完成条件。主要比較の結論・MLB認知妥当性・製品採用は別の状態で報告する。設計PRの作成や技術的整合性の確認を、ユーザーの承認とみなさない。

## 承認後の工程

採用する研究範囲と設計PRのマージ許可を別に記録し、マージされた設計と承認範囲を開発用Codexへ渡す。実装PRは設計側がレビューし、ユーザーの明示許可前にマージしない。
