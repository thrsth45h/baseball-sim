# ADR-0004: 記録集合のEV/LAを固定区分の同時分布として比較する

- Status: **Proposed**
- 設計PR: [ゲームPR #11（Draft）](https://github.com/thrsth45h/baseball-sim/pull/11)。
- DECISIONS ID: 提案D038（OPEN）。D029はOPENを維持。
- ユーザーの明示承認: **未承認**。「次へ」は設計相談の開始で、未提示の新しい学習仕様の承認と扱わない。
- 対象: `phase3a-design-v0.1`

## 現状と問題

Phase 2a接触予測とPhase 2b分類監査は研究として完了。hit_into_playは通常スイング・物理フェアだけを保証せず、EV/LAも欠損や推定値を含む。記録タグの予測を守備前の物理分岐に使う方法は未解決。D022–D023の出来事から記録を作る順序と、D029未較正を守る。

## 推奨と代替

A: 数値の記載されたhit_into_play集合をEV9×LA8の固定区分へ分け、同じ周辺分布を持つ独立抽選J0と同時抽選J1を比べる。小さな後続比較基準として推奨。Bの記録3分類予測は物理分岐を特定せず、Cの連続打球・方向・捕球の同時実装は仮定を広げすぎる。能力較正の先行も行わない。

## 根拠・反証・トレードオフ

対象は記録集合と数値適格条件に選択された分布。ヒット/アウトの事前抽選をゲームへ導入せず、サンプラーも区分だけを返す。この研究だけでは全接触・個人能力・物理フェア・得点を生成できない。区分内の変化を失い、直接測定と推定の個別識別もできない。

各軸独立の一様平滑化epsilon0.01により、同じ周辺・正値・経験的独立表での同値を保つ。仮設定は希少区分を増やす場合があり、結果を見て変更しない。J1優位を完了条件にせず、悪化・定義不能も報告する。

## 入力と年度凍結

既存manifest宣言145件のうち実体確認は年度ごとに実施。2023の47件確認とfit→設定・入力・モデル凍結→2024/2025各49件の確認と評価。未来の実ファイルを先に全件読む工程は作らない。年別到達率と除外内訳を保存し、旧processedの適格条件・分母は変更しない。2025は既閲覧年度。

## 影響と受入れ

[設計v0.1](../PHASE3A_DESIGN.md)のモデル・情報境界・評価・テスト・資源・公開範囲を正本とする。旧研究・モデル・数値を保持する新規namespace。責任者が独立検証し、workerへ直接修正依頼。新しいゲーム仕様やセーブへの変更は含めない。

## 判断を求めること

Aの研究対象、登録raw145件の年度別確認、worker実装開始を相談する。承認後に本人回答・範囲を記録して設計をマージし、実装を委任する。能力換算・連続値生成・方向・守備・ゲーム採用へ承認を拡張しない。
