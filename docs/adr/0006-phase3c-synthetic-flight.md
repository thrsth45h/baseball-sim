# ADR-0006: 合成の軌道と地面到達点への移動余裕を先に検証する

- Status: **Proposed — 本人の仕様承認待ち**
- 設計PR: [ゲームPR #15](https://github.com/thrsth45h/baseball-sim/pull/15)（Draft、未マージ）。
- 対象: [Phase 3c設計v0.1](../PHASE3C_DESIGN.md)
- DECISIONS: D040 OPEN、D029 OPENを維持。
- 「つぎへ」は次案の検討指示であり、未提示の仮定・実装開始の承認とは扱わない。

## 現状と問題

Phase 3bの限定記録集合のEV/LA生成器は研究として完了した。方向・軌道・守備前の情報が揃ったわけではない。記録座標から初期方位が測れたとは確認できず、全量欠損監査だけでも意味は確定しない。観測図の予測研究を増やす前に、生成入力と記録の契約を整理し、初期条件→打球運動→守備側の量という順序を具体化する。

## 提案・代替と反証

固定人工例だけで、無空気/一定重力の軌道と最初の地面到達を解析的に求める。単一守備者の開始位置・移動速度・反応時間から、真の地面到達点に対する移動距離予算と差を計算する。差はpositive_margin / negative_margin / boundaryに分類する。

これは捕球判定ではない。負でも飛行途中に捕れる場合があり、正でも実際の捕球成功は保証されない。合成世界の数式に合っても、MLBの飛距離/守備成績には未検証。球場・反発・複数守備者・走塁・公式記録まで広げない。

全量の座標欠損監査や図上方向の予測は用途決定後に検討する。既存3bとの接続も保留。3bの無上限EVと本案の人工入力範囲を、clipや再抽選で黙って接続しない。

## 影響・検証・承認

[設計書](../PHASE3C_DESIGN.md)の単位・座標・支持範囲・数式・ε・12例・情報境界を正本とする。手計算/別式、対称性、速度/反応の単調性、守備者変更で軌道不変、独立再実行を検証。旧439テストと成果物を保護し、新namespaceだけをworkerへ実装委任する計画。

本人の研究範囲・明示仮定・worker実装開始の承認後に正式化・設計マージする。D040はそれまでOPEN。能力較正・全接触・捕球成功・ゲーム採用の承認には拡張しない。
