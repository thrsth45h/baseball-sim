# ADR-0005: 粗区分確率を揃えて区分内情報と数値抽選を検証する

- Status: **Proposed — 本人の仕様承認待ち**

- 対象: [Phase 3b設計v0.1](../PHASE3B_DESIGN.md)
- ユーザーの「次へ」は次案の検討指示。本案の詳細や実装開始の承認とは扱わない。

## 現状と問題

Phase 3aの72区分研究は完了。数値生成と区分内形状は未実装。既存J0/J1に同じセル内密度を掛けるだけなら、既存の損失差を再度数えることになる。固定epsilon0.01も希少なEV最終区分の確率を増やすため、そのまま尾部数値生成へ使う理由はない。

## 提案・代替・反証

新規H0/H1で同じ72粗区分確率を保つ。5mph×5度の900区分で、粗セル内の基底分布H0と細セル件数を学習したH1を比較する。全体合計1件の擬似度数を固定し、旧J0/J1は保存する。有限セルは一様、EV≥120は尺度5mphの指数形で数値抽選する。全域で積分1、上限切り詰めなし。

KDE等の柔軟な密度は境界・帯域・丸め・計算量の追加設計が必要で保留。任意のEV上限や最終区分の除外も行わない。新H0は旧J1とは別物。主差には細かい周辺と組合せの両方が関係するため、相関だけの効果とは呼ばない。

**900カテゴリの主比較は、5単位内部の一様性・尾部尺度・物理妥当性を検証しない。** 数値を返せることと、記録の小数精度・真の連続分布・全接触を再現できることを分ける。擬似度数1では平滑化が弱いため、少数の観測セルへ集中し、空セルの予測確率が非常に小さくなる場合がある。H1が悪化する反例も残し、改善を完了条件にしない。

## 年度・影響・検証

Phase 3aと同じ登録145ファイル・数値適格条件を年度別に照合。2023だけfit→凍結→2024診断/既閲覧2025比較。後続年度で設定変更しない。旧研究のコード・数値・母集団・モデル・凍結索引は変更しない。

[設計書](../PHASE3B_DESIGN.md)の入力同一性、900→72の確率保存、積分/CDF、情報境界、保存モデルの意味、乱数保存復帰、独立検算を受入条件とする。新namespaceだけの研究実装。能力・方向・守備・得点・ゲーム統合は含めない。
