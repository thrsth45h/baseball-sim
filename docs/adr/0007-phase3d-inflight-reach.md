# ADR-0007: 飛行中の幾何的到達機会を、実際の捕球から分けて検証する

- Status: **Accepted**
- 設計PR: [ゲームPR #17](https://github.com/thrsth45h/baseball-sim/pull/17)。
- DECISIONS: D041は3d合成研究範囲のみCONFIRMED、D029 OPENを維持。
- 対象: [Phase 3d設計v0.1](../PHASE3D_DESIGN.md)
- ユーザーの明示承認記録: **2026-10-29、本人が本PRの範囲を示す確認に「設計PR #17の範囲・仮設定で進める（推奨）」と回答。** 合成研究範囲・明示仮設定とworker実装開始の承認。先の「つぎへ」だけを承認とは扱っていない。

## 現状と問題

Phase 3cは無空気の人工軌道・地面到達・単一守備者の距離予算まで完了した。地面到達点への移動余裕は、飛行途中の機会を表さない。既に守備者が通過点に立っている反例でも、この二つは異なる。

## 案・代替・反証

人工の直交初速と高さから同じ運動方程式を使い、反応後・地面到達前・指定高さ以下・水平移動予算内の時刻集合を求める。三角関数の丸めは扱わず、正規化した入力を正確な有理係数として扱う。二次不等式の区間交差を用い、表示用時間点の間にある機会も検査する。

地面余裕の捕球への読み替え、一定刻みだけの検査は採用しない。実際の捕球確率や知覚まで一度に作る案も保留。真の未来軌道を既知とした存在判定であり、選手の意思決定・実際の成功とは異なる。反応前の機会禁止、水平半径0、高さ上限、即時最大速度は研究仮定である。

## 数値契約・影響

係数の符号・零・共通根を有理数で検査し、異なる代数的根は包囲で比較する。最大512精密化でも比較できなければindeterminateとし、falseにしない。根の表示包囲幅1e−12秒は接触半径/物理精度/区間合体の閾値ではない。単一時刻と地面の開端点を区別する。

研究側の新namespaceのみ。旧3cの実装/出力・旧研究を維持し、実データ/3b・能力・ゲーム・セーブには接続しない。入力範囲・全20例・結果status・受入れ条件は[設計書](../PHASE3D_DESIGN.md)を正本とする。

## 検証・相談する判断

手計算/別方式の期待値、区間全体の照合、根の包囲、接線・退化・地面等号・極小区間、集合包含と対称性、旧497テストと情報境界・再現性を検査する。責任者が実装を独立レビューし、workerへ直接修正依頼する。

本人が合成研究範囲・明示仮設定とworker実装開始を承認した。D041をその範囲だけCONFIRMEDとし、設計PRをマージ後に委任する。D029はOPEN。捕球確率・認知・実データ/3b接続・能力・ゲーム採用は別判断である。
