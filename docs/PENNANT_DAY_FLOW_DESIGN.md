# ペナント上部バーと当日の進行

2026-11-24。本人指定「左上に球団名、順位、勝敗数」「右上進行ボタン」「試合前→試合後スコア表示状態」「もう一度押したら次の日の試合前」「自分の球団のカードを押すと、自分の球団の試合に進む」に基づき、D060の画面とD057の既存進行を接続する。

## 画面と操作

- ペナントの上部バーの左側に操作球団名、所属リーグでの順位、勝・敗・引分を固定する。右側のボタンは「進行」「翌日へ」「翌年へ」など現在の操作を示す。下部5タブと、単独1試合への入口を保持する。単独1試合の切替はペナントの設定からも到達できる配置に整理し、上部バーの情報と重複させない。
- 試合日の「進行」は当日分を既存の進行処理で確定する。確定後も上部の表示日と対戦カードは同じ日を保ち、両リーグの確定スコアを表示する。次の「翌日へ」で表示を翌日に切り替える。この操作で投球・抽選・保存を再実行しない。ホーム以外で明示的に進行を押した場合はホームで対象日を確認できるようにする。
- 休養日は対戦カードがないので、一度の進行で次の日を表示する。最後の試合日も確定スコアを表示してから「シーズン終了」へ進み、対応セーブでは既存の翌年確認へつなぐ。停止予約やエラーで一部しか確定しなかった日は、同日を表示して次の進行で再開できるようにする。
- 当日の操作球団のカードを押すと、そのカードが示す試合へ移動する。試合前は同日の先行試合だけを既存の順序で進め、対象の開始位置で止める。対象が進行中なら同じ試合に移動する。終了済みならその試合の結果を表示する。他球団のカードと休養日は進行操作を持たない。完了カードの押下で翌日や他球団の試合を開始しない。

## 表示と保存

既存の保存上は、当日の最終試合の確定と日程位置の進行が一緒に行われる。上部バーとホームの日付、日程画面を開いた際の初期日は、当日の確定スコアを表示する間は対象日を参照する。表示は試合結果の公開後にだけ切り替え、同じ保存と日付に結び付ける。タブ・画面回転で保持し、新規・手動ロード・翌年開始では解除する。アプリを新しいプロセスとして開き直す場合は、保存済みの日程位置から表示を再開する。試合ログや成績、Roomスキーマと保存形式に新たなデータを加えない。

カードから試合へ移る場合は操作時点の保存トークンと試合IDを確認する。状態が切り替わった直後の古い画面や連打では、同じ試合を重複して始めない。試合を開始する処理は既存の確定順と中断復旧を使う。終了済みカードの結果閲覧は書き込みを伴わない。既存のシーズンスキップと停止予約、セーブ、順位と個人成績は引き続き使える。

## 検証

隔離Android実機相当で、試合日「進行」→同日全スコア→「翌日へ」→翌日試合前までを実タップで確認する。前者は当日分だけを確定し、後者は保存トークン・投球・試合件数を動かさないことを確認する。自球団カードを前・中・後に押した場合の同じ試合への到達、他球団の非操作、休養日、最終日、停止、再読込・世代切替・回転、旧保存を回帰確認する。狭い画面で上部バーと下部タブが読めることを確認し、検証APKを[配布手順](APK_RELEASES.md)に沿って公開する。
